# Kanil portfolio - lower section redesign

## What's changed
- Replaced the 4 overlapping sticky services cards with a responsive 2-column glass-card grid.
- Reduced giant blank areas; each card auto-sizes to its content.
- Added a custom, lightweight navy/cyan ambient grid and layered glow background from Services to Footer, inspired by the mood (not code or media assets) of https://github.com/uzair0x7/Portfolio-React.
- Preserved the hero background, static original photo, existing projects, and contact/admin code.
- Reworded the service CTA to avoid promising a fixed response time.

## Run
Open this project directory in your terminal:

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Notes
This is an adaptation of the existing Next.js project, not a conversion to React CRA. No imagery or assets were copied from the reference repository. Re-check Vercel/Supabase configuration when deploying.
