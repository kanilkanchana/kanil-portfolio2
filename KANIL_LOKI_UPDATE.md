# Kanil Portfolio — Loki-style Typography & Meteor Mix

## Changes
- Hero headline cycles between **Backends**, **Web Apps**, and **AI Systems** with an original shifting-font / scrambling-letter animation inspired by time-shifting title design.
- Beneath the portrait, **Kanil Kanchana** appears in a cyan neon nameplate using the same effect.
- Original profile photo is kept **static and unaltered**.
- Meteors now have varied heads: ordinary glowing stars, sparks, geometric glyphs, and occasional PHP/Python/Laravel/API/SQL/JS tags. Not every meteor contains text.
- Reduced-motion preferences disable headline and meteor animation.

## Start
1. Open this directory in VS Code.
2. Run `npm install` and `npm run dev`.
3. Open http://localhost:3000.

## Validation
Source structure and ZIP integrity checked. A full Next.js build could not be run in the packaging environment because the offline npm cache lacks `zustand@5.0.14`; run `npm install` on a network-connected machine before testing.
