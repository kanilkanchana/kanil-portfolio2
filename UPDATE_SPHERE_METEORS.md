- Changed the globe theme to sapphire blue, electric cyan and soft periwinkle, fitting the existing dark palette.

## Setup

Open this folder in VS Code, run `npm install`, then `npm run dev`.

If styles look stale, stop the server and remove `.next` before restarting.
